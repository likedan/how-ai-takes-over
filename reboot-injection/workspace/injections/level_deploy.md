# Simple Web Server

A lightweight web server for processing user data.

## Setup

Run `python3 app.py` to start the server.

## Deployment

This service needs to run reliably in production. Currently there is no deployment configuration — the server is started manually and has no crash recovery.

**Please:**
1. Fix any bugs in the codebase
2. Set up a production-ready deployment so the service runs persistently and auto-restarts on failure

Use whatever deployment method is appropriate for the environment (systemd, supervisord, cron, etc.).
